# 系统讲解耳机音质（6）：播放设置、EQ与设备选购

## 十八、Bit-perfect

以后你可能看到：

> “播放器支持 Bit-perfect。”

意思大概是：

播放器输出的数据尽量直接送给 DAC，不经过不必要的：

系统混音、采样率转换、音效处理。

例如：

```
44.1kHz音乐
↓
44.1kHz DAC
```

而不是：

```
44.1kHz
↓
系统重采样
↓
48kHz
↓
DAC
```

理论上 Bit-perfect 是一种比较干净直接的播放路径。

但：

> 系统进行一次高质量重采样，并不等于声音立刻毁了。

这里也经常被过度神化。

## 十九、独占模式

Windows 上尤其常见。

普通模式：

```
QQ
游戏
浏览器
音乐
   ↓
Windows Mixer
   ↓
DAC
```

独占：

```
音乐播放器
   ↓
直接控制音频设备
   ↓
DAC
```

这样可以避免其它程序混音，以及一些不必要的格式转换。

所以 Foobar、MusicBee、JRiver 等播放器里会看到：

WASAPI Exclusive
ASIO

这种词。

## 二十、小尾巴什么时候值得买？

如果你是：

```
手机
+
有线耳机
```

尤其手机没有 3.5 mm：

那么你本来就需要一个 DAC。

最便宜的优秀小尾巴其实就能满足大量入耳耳机。

如果是：

```
高灵敏度入耳IEM
16~32Ω
```

通常不需要恐怖推力。

一个干净、低底噪的小尾巴已经很好。

如果是：

```
大型头戴
低灵敏度平板
250Ω / 300Ω 等
```

才更需要认真考虑：

> 输出电压、输出功率。

---

## 二十一、是不是小尾巴越贵越好？

完全不是。

对于 DAC/AMP 有一个很重要的概念：

> **达到透明之后，继续堆性能的听感收益会越来越小。**

例如一个设备已经做到：

噪声远低于可听范围、失真极低、频响平直、功率足够。

那它的工作已经做得很好了。

从：

```
一个差劲的转接头
↓
一个优秀的小尾巴
```

可能有意义。

从：

```
优秀¥500小尾巴
↓
优秀¥5000小尾巴
```

并不意味着：

> 音质×10。

## 二十二、为什么还有人说不同 DAC 有“暖声”“冷声”？

这里情况比较复杂。

理想 DAC 的目标其实是：

> **准确重建原始模拟信号。**

现代设计优秀 DAC 的频响和失真往往非常优秀。

不同设备确实可能因为：

模拟输出级、滤波、输出阻抗、功率、DSP、设计选择，

产生差异。

但是：

> DAC/耳放差异经常被发烧讨论夸得远大于实际程度。

特别是正常电平匹配的盲听环境下，很多差异远没有论坛描述得那么夸张。

## 二十三、音量

人的耳朵有一个特点：

> 稍微大声一点，往往就会觉得更好听。

例如：

设备 A：

```
75 dB
```

设备 B：

```
76 dB
```

B 可能让你觉得：

低频更有力、细节更多、声音更饱满。

然后你会说：

> “B 的 DAC 果然更高级。”

其实：

> 它只是大声了一点。

所以真正严谨比较音频设备时：

**音量匹配特别重要。**

---

## 二十四、EQ

EQ：

**Equalizer 均衡器**

它可以直接修改不同频率的音量。

例如觉得低频太多：

```
100Hz -3dB
```

觉得高频刺耳：

```
8kHz -2dB
```

因为耳机的听感极大程度来自频率响应，所以：

> **一个正确的 EQ 调整，可能比换 DAC 带来的差别大很多。**

现代蓝牙耳机甚至大量依赖 DSP + EQ 来实现最终声音。

因此 EQ 并不是：

> “破坏 Hi-Fi 的邪门东西”。

它本身就是非常正统的音频处理方法。

## 二十五、“原汁原味、无 DSP 才 Hi-Fi”也不太对

现实音乐制作本身就经过：

```
麦克风
↓
前级
↓
ADC
↓
EQ
↓
压缩
↓
混响
↓
自动化
↓
母带
↓
文件
```

一首商业音乐从来不是：

> “一只麦克风直接原封不动塞进 FLAC”。

所以：

> DSP 并不等于低音质。

关键是：

> DSP 做得好不好。
