# 系统讲解耳机音质（1）：播放链路与数字基础

## 一、先搞懂：一首歌到底是怎么跑进你耳朵里的？

最基本的有线播放链路是：

**音乐文件 → 软件解码 → 数字音频 PCM → DAC → 模拟电信号 → 耳放 → 耳机 → 声音**

比如你手机里有一首 FLAC：

```
FLAC 文件
   ↓
手机把 FLAC 解码
   ↓
PCM 数字音频
   ↓
DAC（数字 → 模拟）
   ↓
耳放把信号放大
   ↓
耳机单元振动
   ↓
空气振动
   ↓
你的耳膜
```

这里最关键的几个东西分别是：

| 名⁠称            | 干⁠什⁠么                                    |
| ---------------- | ------------------------------------------- |
| FLAC / MP3 / AAC | 储⁠存⁠音⁠乐⁠的⁠编⁠码⁠方⁠式                  |
| PCM              | 解⁠码⁠之⁠后⁠的⁠数⁠字⁠声⁠音                  |
| DAC              | Digital-to-Analog Converter，数⁠字⁠转⁠模⁠拟 |
| 耳⁠放 AMP        | 把⁠模⁠拟⁠信⁠号⁠放⁠大⁠到⁠足⁠以⁠驱⁠动⁠耳⁠机   |
| 耳⁠机⁠单⁠元      | 把⁠电⁠信⁠号⁠变⁠成⁠实⁠际⁠空⁠气⁠振⁠动         |

而蓝牙会变成：

```
音乐文件
↓
解码为 PCM
↓
再次用蓝牙编码器压缩
↓
Bluetooth 无线传输
↓
耳机收到数据
↓
蓝牙解码
↓
耳机内部 DAC
↓
耳机内部耳放
↓
耳机单元
```

所以：

> **有线耳机通常把 DAC 和耳放放在手机、小尾巴或播放器里。**
>
> **蓝牙耳机则把 DAC、耳放、电池、蓝牙芯片、DSP 全塞进耳机里面。**

理解这一点以后，很多问题一下就清楚了。

## 二、什么是“数字音频”？

现实里的声音本质是连续变化的空气压力。

比如一个正弦波：

```
空气压力

   /‾\      /‾\
  /   \    /   \
 /     \__/     \__
```

这是连续的。

但电脑不能直接储存无限连续的东西，所以要不断“测量”这个波。

例如：

```
真实声音：

~~~~~~~连续波形~~~~~~~

电脑记录：

•   •   •   •   •
  •   •   •   •
```

这种过程叫：

**采样 Sampling**

由此出现音频圈最常见的两个参数：

**采样率 Sample Rate**

以及

**位深 Bit Depth**。

## 三、44.1 kHz、48 kHz、96 kHz到底是什么？

假设：

**44.1 kHz**

意思就是：

> 每秒测量声音 **44100 次**。

48 kHz：

> 每秒 48000 次。

96 kHz：

> 每秒 96000 次。

所以：

```
44.1 kHz
= 44100 samples / second

96 kHz
= 96000 samples / second
```

为什么 CD 是 44.1 kHz？

因为根据奈奎斯特采样定理，要记录最高频率 $f$，采样率至少需要超过：

$$
2f
$$

人类听觉通常认为上限大约在：

$$
20\text{kHz}
$$

所以：

$$
44.1\text{kHz}/2=22.05\text{kHz}
$$

已经足够覆盖正常人类听觉范围。

**直观的理解奈奎斯特采样定理**

假设有一个正弦波：

$$ x(t)=\sin(2\pi ft) $$

如果它的频率是：

$$ f=1\text{ kHz} $$

那么按照奈奎斯特采样定理：

$$ f_s>2\text{ kHz} $$

才能理论上恢复这个波形。

为什么至少需要两倍？

因为一个周期至少需要取得足够的信息，才能区分：

它到底是在上升还是下降
到底是一个低频波还是另一个高频波

如果采样太慢，不同频率的连续信号可能产生完全相同的采样点。

这就叫：

$$ \boxed{\text{混叠 Aliasing}} $$

因此有一个很重要的认知：

> **96 kHz 并不是“声音比 44.1 kHz 细两倍”。**

这是一种非常常见的误解。

96 kHz 主要在录音、混音、音频处理等环节有技术价值；对于最终播放而言，**44.1/48 kHz 本身已经可以实现完整的可听频段重建**。

## 四、那 16 bit、24 bit 又是什么？

采样率决定：

> 横轴——多久记录一次。

位深决定：

> 纵轴——每次记录有多精细。

可以粗略想成：

```
采样率 = 横向分辨率
位深   = 纵向分辨率
```

16 bit 每次采样可以表示：

$$
2^{16}=65536
$$

个等级。

24 bit：

$$
2^{24}=16777216
$$

个等级。

位深尤其影响**量化噪声和理论动态范围**。

理想情况下大概可以记：

$$
动态范围 \approx 6.02\times bit
$$

所以：

16 bit：

$$
约96\text{ dB}
$$

24 bit：

$$
约144\text{ dB}
$$

96 dB 已经是非常巨大的动态范围。

所以：

> **24 bit 对录音、制作非常有意义，因为制作过程中需要很大的处理余量。**
>
> 但“24 bit 成品一定明显比 16 bit 好听”就不是这么简单了。

这也是 Hi-Res 音频宣传中特别容易让人误解的地方。

## 五、码率 kbps 又是什么？

码率是：

> **每秒要传输多少数据。**

比如 CD 规格：

44.1 kHz × 16 bit × 双声道：

$$
44100\times16\times2
$$

等于：

$$
1,411,200\text{ bit/s}
$$

也就是：

**1411 kbps**

所以未经压缩的 CD PCM 音频数据量大约：

> 1411 kbps。

这时候你应该能理解为什么 MP3 320 kbps 小这么多了：

```
CD PCM        ≈ 1411 kbps
MP3           ≈ 320 kbps
AAC           ≈ 256 kbps
```

因为 MP3 / AAC 会进行**有损压缩**。
