# 系统讲解耳机音质（2）：音频文件格式与高规格音频

## 六、WAV、FLAC、ALAC、MP3、AAC到底是什么？

这是很多人的第一个大坑。

它们属于“音频编码/文件格式”这一层。

可以先这样理解：

| 格⁠式 | 类⁠型                   | 特⁠点                      |
| ----- | ----------------------- | -------------------------- |
| WAV   | 通⁠常⁠未⁠压⁠缩 PCM      | 文⁠件⁠巨⁠大                |
| AIFF  | 通⁠常⁠未⁠压⁠缩 PCM      | 类⁠似 WAV                  |
| FLAC  | 无⁠损⁠压⁠缩             | PC/Android 很⁠常⁠见        |
| ALAC  | 无⁠损⁠压⁠缩             | Apple 推⁠广                |
| MP3   | 有⁠损⁠压⁠缩             | 非⁠常⁠普⁠及                |
| AAC   | 有⁠损⁠压⁠缩             | Apple/视⁠频/流⁠媒⁠体⁠常⁠见 |
| Opus  | 有⁠损⁠压⁠缩             | 效⁠率⁠非⁠常⁠高             |
| DSD   | 特⁠殊⁠数⁠字⁠音⁠频⁠体⁠系 | 发⁠烧⁠领⁠域⁠比⁠较⁠常⁠见    |

## 七、FLAC为什么能变小，又不损失声音？

FLAC 属于：

**Lossless 无损压缩**

这和 ZIP 很像。

例如原始数据：

```
AAAAAAAAAABBBBBBBBBBCCCCCCCCCC
```

可以记录成类似：

```
10A 10B 10C
```

虽然储存方式变了，但可以 **100% 恢复原始数据**。

所以：

```
WAV
 ↓
FLAC压缩
 ↓
FLAC文件
 ↓
解压
 ↓
原来的PCM
```

理论上：

**WAV → FLAC → WAV**

数据可以完全恢复。

Apple 的无损格式 ALAC 原理类似。Apple Music 的无损曲库使用 ALAC，并提供从 16-bit/44.1 kHz 到最高 24-bit/192 kHz 的内容。

所以：

> **FLAC 并不是比 WAV 音质差一点。**
>
> 正常正确解码后，它们可以得到完全相同的 PCM 数据。

## 八、MP3 / AAC 为什么叫“有损”？

它们不是单纯把数据压缩，而是：

> **把算法认为人耳不容易听出来的信息删除。**

例如一个很响的声音旁边有非常弱的声音，人耳可能因为“掩蔽效应”听不到那个弱声音。

编码器就可能认为：

> 那这部分可以少记录一点。

因此：

```
原始音频
↓
心理声学分析
↓
删除/简化不重要信息
↓
MP3/AAC
```

解码的时候：

> 被扔掉的信息不能真正恢复。

所以叫：

**Lossy 有损压缩。**

但这里又有一个很重要的问题：

> **有损 ≠ 一定难听。**

高质量 AAC、Opus、MP3 在足够高码率下，很多情况下已经非常难和无损区分。

## 九、AAC 的两个场景

你以后很容易看到：

> “Apple Music AAC”

以及：

> “蓝牙 AAC”。

虽然都叫 AAC，但要分清楚所处位置。

例如：

```
Apple Music AAC 文件
        ↓
手机解码
        ↓
PCM
        ↓
AAC 蓝牙重新编码
        ↓
AirPods
```

也就是说：

**音乐文件编码**和**蓝牙传输编码**是两个不同的问题。

甚至可能发生：

```
FLAC无损
↓
解码成PCM
↓
蓝牙AAC压缩
↓
耳机
```

所以：

> “我播放的是 FLAC 无损”

并不代表：

> “整个播放链路都是无损。”

Apple 官方也明确说明：AirPods、AirPods Pro、AirPods Max 等无线产品通过 AAC 蓝牙编码传输，而**蓝牙连接并非无损**。

## 十、“母带”可能比 FLAC/MP3重要得多

这是非常重要但小白阶段经常没人告诉你的事情。

假设：

版本 A：

```
24bit / 192k FLAC
```

但是母带：

压缩严重、削波、混音差。

版本 B：

```
16bit / 44.1k FLAC
```

但是：

录音、混音、母带都非常优秀。

B 完全可能明显更好听。

所以：

> **音源质量 ≠ 文件数字规格。**

## 十一、DSD

你可能看到：

```
DSD64
DSD128
DSD256
```

DSD 是另一种数字声音表示方式。

普通音乐常见：

**PCM**

例如：

```
16bit / 44.1k
24bit / 96k
```

DSD 则采用：

> 非常高采样率 + 1 bit 调制

的思路。

它在 SACD 和 Hi-Fi 圈比较常见。

但对于刚入门：

> **完全不用优先研究 DSD。**

更不要产生：

> DSD256 > DSD128 > PCM > MP3

这种简单排行榜。

没有意义。

---

## 十二、Hi-Res Audio

你看到那个：

**Hi-Res AUDIO**

金色标，经常会觉得：

> “这一定音质特别好。”

它更接近：

> 产品支持一定规格的高解析度音频。

例如：

24bit / 96kHz。

它不能证明：

耳机频响优秀、失真优秀、调音优秀、你一定喜欢。

所以：

> **Hi-Res 是能力规格，不是音质评分。**

Qualcomm 现在也会把 aptX Adaptive 等方案标为支持 24-bit/96 kHz；LDAC 也强调高解析度内容的蓝牙传输。

但是：

> “能够传 24/96”

和：

> “声音一定比 16/44.1 好”

完全是两回事。
