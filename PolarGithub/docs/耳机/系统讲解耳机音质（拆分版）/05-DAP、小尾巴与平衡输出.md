# 系统讲解耳机音质（5）：DAP、小尾巴与平衡输出

## 为什么手机推不好某些大耳？

假设耳机需要比较高的电压。

手机小小一个：

```
电池
CPU
屏幕
基带
Wi-Fi
相机
……
```

还要控制：

功耗、发热、体积。

所以它没必要专门安装非常强大的耳放。

专业播放器则可以：

```
更高电源电压
↓
更强耳放
↓
更高输出电压/电流
↓
驱动困难耳机
```

所以才会有人说：

> “这个耳机手机推不开。”

严格说应该理解成：

> 手机的耳机输出达不到这个耳机理想需要的电压/电流条件。

---

## “推不开”并不只是音量小

这里又有一个容易误解的问题。

很多人说：

> “我手机明明能把它推得很响啊。”

“响”只代表：

> SPL 足够。

但还可能存在余量不足、低频动态时功率不足、削波等情况。

如果一个 DAC/AMP：

电压够、功率够、噪声低、失真低、输出阻抗合理，

那它已经完成任务了。

并不是：

> “换成 2 万元耳放就一定释放隐藏的 40% 音质。”

---

## 所以专业播放器 DAP 到底比手机多了什么？

专业播放器英文：

**DAP = Digital Audio Player**

比如一些 Sony、FiiO、Astell&Kern、山灵、海贝播放器。

它本质是：

```
一台专门为了播放音乐设计的小电脑
```

它通常会把大量空间用于：

```
音频DAC
耳放
供电
时钟
输出接口
屏蔽
散热
```

而手机主要目标是：

```
通信
拍照
性能
屏幕
续航
体积
```

所以专业播放器可能拥有：

| 项⁠目                | 手⁠机             | 专⁠业⁠播⁠放⁠器       |
| -------------------- | ----------------- | -------------------- |
| DAC                  | 有/外⁠置          | 专⁠门⁠设⁠计          |
| 耳⁠放                | 通⁠常⁠较⁠弱/无3.5 | 可⁠以⁠很⁠强          |
| 3.5mm                | 常⁠没⁠有          | 常⁠有                |
| 4.4mm                | 基⁠本⁠没⁠有       | 很⁠常⁠见             |
| 大⁠功⁠率⁠输⁠出       | 一⁠般             | 常⁠见                |
| 本⁠地⁠音⁠乐⁠管⁠理    | 普⁠通             | 专⁠门⁠优⁠化          |
| microSD              | 很⁠少             | 很⁠常⁠见             |
| 高⁠规⁠格⁠格⁠式⁠支⁠持 | 看⁠系⁠统          | 通⁠常⁠很⁠齐          |
| 电⁠池                | 所⁠有⁠功⁠能⁠共⁠用 | 主⁠要⁠给⁠播⁠放⁠使⁠用 |

## 手机加小尾巴

假设你使用：

```
iPhone
↓
一个性能优秀的小尾巴
↓
容易驱动的入耳耳机
```

那么整个链路实际上已经可以非常优秀。

换成：

```
¥5000 DAP
```

未必会出现：

> “哇，音质突然翻倍。”

很多情况下：

**手机 + 好小尾巴**

已经完全可以作为非常高质量的有线音源。

专业播放器最大的价值可能反而是：

专门听歌、独立电池、实体键、microSD、接口丰富、大推力、不被手机通知打扰。

而不是：

> “它内部有什么神秘音频魔法。”

---

## 如果使用蓝牙耳机，专业播放器优势甚至更小

假设：

```
¥8000播放器
↓
LDAC
↓
蓝牙耳机
```

和：

```
Android手机
↓
LDAC
↓
同一耳机
```

最终：

DAC 和耳放都在：

**蓝牙耳机内部。**

播放器自己的高级 DAC 根本没有参与。

所以对于蓝牙：

> 发送端最主要的意义是 Bluetooth Codec、连接稳定性、系统处理等。

这时候：

**“播放器用了什么顶级 DAC 芯片”**

基本和你的蓝牙耳机没有直接关系。

---

## 为什么 iPhone 听 Hi-Res 经常推荐小尾巴？

因为 iPhone 自己没有模拟耳机接口。

而且 Apple 官方明确说明，如果要在 iPhone 上播放采样率高于 **48 kHz** 的 Apple Music 音频，需要外接 DAC。

所以：

```
Apple Music
24bit / 96k
↓
iPhone USB-C
↓
外置DAC
↓
有线耳机
```

是非常正常的方案。

---

## 买小尾巴究竟是在买什么？

主要买的是这几样东西：

**DAC性能**

数字转模拟是否足够干净。

**耳放性能**

能输出多少电压、电流和功率。

**噪声**

尤其高灵敏度入耳耳机，如果设备底噪大：

```
嘶————
```

很烦。

**失真**

例如 THD+N。

**接口**

3.5 mm、4.4 mm。

**功能**

硬件音量键、EQ、滤波、USB模式、手机 App 等。

## 4.4 平衡

以后遇到：

> 3.5 单端

以及：

> 4.4 平衡。

简单理解：

普通单端：

```
L+
R+
共享 Ground
```

平衡驱动则可以：

```
L+ L-
R+ R-
```

每个声道采用独立差分驱动。

这样设计很容易得到更高输出电压。

因为：

$$
V_{diff}=V_+-V_-
$$

所以很多设备：

```
3.5mm：100mW
4.4mm：400mW
```

看起来 4.4 推力明显更大。

---

## 但是“平衡一定音质更好”也是误区

平衡输出可以带来一些工程优势，例如：

更大的输出功率、通道分离设计方便等。

但是：

> **4.4 mm 本身并不会自动让声音更高级。**

一个设计优秀的：

```
3.5单端
```

完全可以比设计一般的：

```
4.4平衡
```

表现更好。

所以：

> 平衡首先是一种电路和传输方式，而不是“音质增强按钮”。
