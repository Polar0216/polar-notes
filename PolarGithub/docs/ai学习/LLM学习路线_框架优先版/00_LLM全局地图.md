# 第 0 课：从预测任务推导出 GPT 的结构

这节课不从组件名单开始。我们先规定模型必须完成的任务，再逐项观察会遇到的具体困难。每当一个困难出现，才引入解决它的组件。

这种讲法与 3Blue1Brown 的 Transformer 可视化课程采用相近的认知顺序：先追踪 token 向量怎样逐步吸收上下文，再讨论执行这种更新的矩阵。这里会继续走到可运行代码，但不会把可视化类比当成模型真实机制的证明。

官方参考：

- [Transformers, the tech behind LLMs](https://www.3blue1brown.com/lessons/gpt/)
- [Attention in transformers, step-by-step](https://www.3blue1brown.com/lessons/attention/)

## 1. 唯一任务是预测下一个 token

先把词表缩小为五个候选：

```text
我、爱、猫、狗、鱼
```

输入：

```text
我爱
```

模型要输出的不是一个隐藏的“标准答案”，而是五个候选的分数或概率，例如：

```text
猫  62%
狗  18%
鱼  12%
我   5%
爱   3%
```

选出或采样出“猫”以后，输入变成“我爱猫”，模型再预测下一个 token。长文本生成就是这个步骤不断重复。

这一任务给整个网络规定了两个端点：

```text
起点：一段文字
终点：词表中每个候选 token 的概率
```

下面所有组件都服务于这两个端点之间的转换。

## 2. 输入表示解决文字无法直接计算的问题

### 2.1 Tokenizer 建立文字与编号的确定映射

矩阵运算不能直接接收 Python 字符串。最直接的处理是先为词表中的 token 分配整数编号：

```text
我 → 1
爱 → 2
猫 → 3
狗 → 4
鱼 → 5
```

于是：

```text
"我爱" → [1, 2]
```

执行这组确定映射的组件叫 Tokenizer：

```text
encode：文本 → token id
decode：token id → 文本
```

数字大小没有语义。`猫=3` 不表示猫比 `爱=2` 多一个单位，也不表示编号相近的 token 含义相近。id 只用于定位词表项。

### 2.2 Embedding 把离散编号变成可学习向量

整数 id 只是索引，不能直接表达一个 token 可用于预测的多种特征。模型需要为每个 id 保存一组可训练数字：

```text
我 → [ 0.2,  0.7, -0.3, ...]
爱 → [ 0.8,  0.1,  0.4, ...]
猫 → [ 0.6, -0.2,  0.9, ...]
```

这组可训练向量来自 Embedding 矩阵：

$$
E\in\mathbb{R}^{V\times C}
$$

$V$ 是词表大小，$C$ 是每个 token 向量的维度。输入 id $i$ 时，模型读取第 $i$ 行：

$$
x_i=E[i]
$$

开始训练前，这些数值通常接近随机。训练使它们逐渐变成对下一个 token 预测有用的表示。所谓“向量方向可能携带某种特征”，是训练结果的一种观察方式，不意味着人为提前规定了每个坐标的含义。

### 2.3 位置信息区分相同 token 的不同顺序

只查 token embedding 时，“猫咬狗”和“狗咬猫”包含相同的三个 token 向量。模型还必须知道每个向量位于第几个位置，否则难以表示顺序差异。

教学代码为每个位置也保存一个向量：

```text
第 0 个 token 的初始状态 = token 向量 + 位置 0 向量
第 1 个 token 的初始状态 = token 向量 + 位置 1 向量
第 2 个 token 的初始状态 = token 向量 + 位置 2 向量
```

这就是可学习绝对位置 Embedding。现代模型还可能使用 RoPE 等方法，但它们解决的共同问题相同：把顺序或相对位置带入后续计算。

完成输入表示后，数据第一次呈现出重要形状：

```text
token ids       [B,T]
hidden states   [B,T,C]
```

第一次阅读时只需把它读成：一批文本，每条有若干 token，每个 token 现在由一串数字表示。第 3 章会再解释每个轴。

## 3. 上下文变换解决孤立向量含义不足的问题

### 3.1 Attention 根据上下文更新每个位置

Embedding 查表只看 token 身份。同一个 token 出现在不同句子中，会得到相同的初始 token 向量：

```text
苹果很甜。
苹果发布了新产品。
```

“苹果”的具体含义需要由周围内容确定。Transformer 的目标不是一直保留初始查表结果，而是把每个位置的向量逐层更新为包含上下文的表示。

最简单但效果有限的方案，是把所有可见位置平均后交给当前位置。问题是不同位置的相关程度不同，而且相关位置会随当前内容变化。

Attention 提供一种可学习的选择机制：当前位置对可见位置计算相关分数，用归一化权重对信息进行加权汇总。

先看目标，不看公式：

```text
输入：每个位置当前的向量
处理：为当前位置选择并汇总相关的历史信息
输出：加入上下文更新后的向量
```

输入和输出形状相同：

```text
[B,T,C] → Attention → [B,T,C]
```

这并不意味着内容没变，只表示每个 token 仍由 $C$ 个数字表示。

### 3.2 Query、Key、Value 分离匹配依据与传递内容

为了按内容选择信息，至少要解决两件事：

1. 当前读取位置与哪些历史位置相关。
2. 选中某个位置后，应当传回什么信息。

用于判断相关性的表示，不一定等于真正需要传递的内容。因此同一个隐藏状态 $X$ 被投影为三种用途：

$$
Q=XW_Q,
\qquad
K=XW_K,
\qquad
V=XW_V
$$

- Query 表示当前读取位置用于匹配的需求特征。
- Key 表示每个候选位置用于被匹配的特征。
- Value 表示该位置实际参与加权汇总的内容。

例如处理代词“她”时，某些注意力计算可能需要让当前位置更多读取前文人物相关的信息。这个例子只说明机制能够表达的行为，不表示我们能把真实模型中的某个头永久命名为“代词头”。

先有“动态选择并传递信息”的要求，才出现 Q、K、V；不是因为 Transformer 形式上规定必须把 $X$ 无理由乘三次。

### 3.3 Causal Mask 保证训练与生成的可见信息一致

训练时为了并行计算，会把一段序列整体放入内存：

```text
输入：我 爱 猫
目标：爱 猫 。
```

如果预测“猫”的位置能够读取右侧已经出现的“猫”，模型就会直接利用答案。训练损失可能很好，真正生成时右侧答案却不存在。

Causal Mask 把未来位置的注意力分数设为 $-\infty$，Softmax 后对应权重为 0：

```text
位置 0：只读取 0
位置 1：读取 0、1
位置 2：读取 0、1、2
```

它不是为了提升表达能力，而是自回归训练必须遵守的信息约束。

### 3.4 MLP 继续加工已经汇总的信息

Attention 的主要输出是不同 Value 的加权组合。它解决“从哪些位置取得多少信息”，但取得信息后，还需要具有非线性表达能力的计算在当前 token 内部重新组合特征。

MLP 对每个位置独立应用同一组参数：

```text
Attention：位置之间交换信息
MLP：每个位置内部加工信息
```

两者输入输出都保持 `[B,T,C]`，因此可以交替堆叠。MLP 常先把最后一维扩大，再压回 $C$：

$$
[B,T,C]\longrightarrow[B,T,4C]\longrightarrow[B,T,C]
$$

公式与倍率放到第 5 章细讲。这里先掌握 Attention 与 MLP 解决的是不同问题。

### 3.5 Residual 与 LayerNorm 支持深层堆叠

如果子层输出直接替换旧状态：

$$
x_{\text{new}}=f(x)
$$

每一层既要加入新信息，也要重新保住旧信息。网络变深后，这会增加优化难度。Residual 改为：

$$
x_{\text{new}}=x+f(x)
$$

子层只需学习对当前表示的增量修正，旧表示有一条直接保留路径。这个加法要求两侧形状完全一致。

另一方面，隐藏状态经过许多矩阵乘法、非线性和相加后，数值尺度会不断变化。后续层面对不断漂移的输入分布时，优化会更困难。LayerNorm 在每个 token 的特征维上重新调整尺度，并保留可学习的缩放和平移。

因此：

```text
Residual：让子层学习增量，并保留直接信息与梯度路径
LayerNorm：让进入子层的数值尺度更容易控制
```

它们主要属于深层网络的训练与优化设计，而不是“预测下一个 token”在逻辑上唯一可能的做法。

## 4. 输出层解决内部表示与词表候选不一致的问题

### 4.1 LM Head 把 $C$ 维状态投影到 $V$ 个分数

经过多个 Transformer Block 后，每个位置仍是 $C$ 维隐藏状态：

```text
hidden [B,T,C]
```

但任务要求为词表中的 $V$ 个候选分别打分。两者最后一维含义不同，所以需要一个线性投影：

$$
\text{logits}=HW_{\text{vocab}}+b
$$

形状为：

$$
[B,T,C]\times[C,V]\longrightarrow[B,T,V]
$$

它并不是把整个三维数组“硬乘”矩阵，而是把其中 $B\times T$ 个长度为 $C$ 的 token 向量，分别乘同一个 `[C,V]` 矩阵。第 3 章会用具体数字完整展开。

### 4.2 Softmax 把任意分数变成概率分布

Linear 输出可以是负数，也不要求总和为 1：

```text
猫  4.8
狗  3.1
鱼  1.7
```

这些原始分数叫 logits。为了按概率采样，需要把同一位置的全部 $V$ 个候选一起归一化：

$$
p_i=\frac{e^{z_i}}{\sum_{j=1}^{V}e^{z_j}}
$$

于是得到：

```text
猫  0.62
狗  0.18
鱼  0.12
……
总和为 1
```

在 `[B,T,V]` 上使用 `dim=-1`，含义是让最后一个下标，也就是词表下标 $v$ 变化，对每个固定的 $(b,t)$ 分别进行一次 Softmax。它不是笼统地表示“对列”或“对行”。第 3 章会专门解释轴方向。

## 5. 学习机制解决参数修改方向未知的问题

模型开始时大多参数接近随机，所以正确 token“猫”的概率可能很低。训练必须依次回答三个不同问题。

### 5.1 Cross Entropy 把预测质量压缩为标量

正确 token 的概率为 $p_y$ 时，单位置损失为：

$$
L=-\log p_y
$$

正确答案概率越低，损失越大。它把整批预测质量变成可优化的标量，但还没有说明每个参数该怎样修改。

### 5.2 Backpropagation 计算每个参数的影响方向

损失由 LM Head、Transformer、Embedding 等许多操作共同产生。链式法则从 loss 向后计算：

$$
\frac{\partial L}{\partial\theta}
$$

这个值表示参数 $\theta$ 发生微小变化时，损失在局部怎样变化。`loss.backward()` 负责计算梯度，不直接更新参数。

### 5.3 Optimizer 使用梯度更新参数

最简单更新为：

$$
\theta_{\text{new}}
=
\theta_{\text{old}}-eta\frac{\partial L}{\partial\theta}
$$

优化器根据梯度和学习率执行更新。`optimizer.step()` 才真正改变参数。

一次训练步骤因此固定为：

```python
optimizer.zero_grad()
logits, loss = model(x, targets)
loss.backward()
optimizer.step()
```

## 6. 完整结构在推导后出现

现在再看整台模型，每个组件都有明确来由：

```text
文字
  │ 字符串不能直接进入矩阵计算
  ▼
Tokenizer
  │ id 只是离散编号
  ▼
Token Embedding + Position
  │ 初始向量缺少上下文
  ▼
Transformer Block × N
  ├─ Attention：按内容选择并汇总其他位置的信息
  ├─ MLP：逐位置非线性加工
  ├─ Residual：保留旧状态并叠加增量
  └─ LayerNorm：控制深层计算的数值尺度
  │ 内部状态宽度 C 不等于词表大小 V
  ▼
LM Head
  │ 任意实数还不是概率
  ▼
logits [B,T,V] → Softmax → 下一个 token 概率
```

训练在旁边增加：

```text
logits + 正确 targets
→ Cross Entropy：错误有多大
→ Backpropagation：每个参数对错误有何影响
→ Optimizer：实际修改参数
```

## 7. 组件所属层级避免概念混放

| 组件 | 直接解决的问题 | 性质 |
|---|---|---|
| Tokenizer | 字符串无法直接参与张量计算 | 输入接口 |
| Embedding | id 没有连续可学习特征 | 表示方法 |
| Position | token 身份本身不包含顺序 | 序列信息 |
| Attention | 当前表示需要按内容取得上下文 | 上下文交互方法 |
| Q、K、V | 区分匹配需求、匹配依据与传递内容 | Attention 实现设计 |
| Causal Mask | 训练时不得读取未来答案 | 自回归约束 |
| Multi-head | 一套匹配与更新空间容量有限 | 架构增强 |
| MLP | 加权汇总后仍需非线性加工 | 特征变换 |
| Residual | 深层网络需要保留旧状态与直接梯度路径 | 优化设计 |
| LayerNorm | 深层计算的数值尺度需要稳定 | 优化设计 |
| LM Head | 内部 $C$ 维表示需要变成 $V$ 个候选分数 | 输出接口 |
| Softmax | 任意分数需要变成概率分布 | 概率转换 |
| Cross Entropy | 训练需要一个预测错误标量 | 训练目标 |
| Backpropagation | 每个参数的修改方向未知 | 求梯度机制 |
| AdamW | 已知梯度后需要具体更新规则 | 优化算法之一 |

这张表很重要：这些组件不是同一级别的“天经地义的必需品”。有些由任务约束直接逼出，有些是 Transformer 的架构选择，有些主要为了让深层训练可行。

## 8. 第一遍只保留四层记忆

