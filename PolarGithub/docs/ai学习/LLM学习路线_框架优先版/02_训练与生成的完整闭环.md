# 第一遍之二：训练与生成的完整闭环

本章仍然把 Transformer 内部当作一个保持形状 `[B,T,C]` 的处理器，重点区分两条外部流程：模型如何从正确答案学习，以及模型如何在没有正确答案时逐 token 生成。

## 1. 同一个模型的两种运行方式

训练和生成共享同一个 `MiniGPT.forward()`：

```text
token ids [B,T]
→ embedding [B,T,C]
→ transformer [B,T,C]
→ lm head [B,T,V]
→ logits
```

分歧发生在 logits 之后：

```text
                    ┌─ targets → cross entropy → backward → 更新参数
logits [B,T,V] ─────┤
                    └─ 最后位置 → softmax → 采样 → 接回输入
```

训练路径的目的是改变参数，生成路径的目的是产生新 token。

## 2. 连续文本变成训练样本

假设语料编码后得到：

```text
[我, 爱, 猫, 。, 猫, 爱, 鱼, 。]
```

当 `block_size=4`，从第一个位置截取的样本为：

```text
x = [我, 爱, 猫, 。]
y = [爱, 猫, 。, 猫]
```

`y` 是同一段序列整体向左错开一个位置。代码为：

```python
x = data[i : i + block_size]
y = data[i + 1 : i + block_size + 1]
```

每个位置都形成一个“根据左侧上下文预测下一个 token”的监督信号。

| 输入位置 | 模型允许看到的内容 | 对应目标 |
|---|---|---|
| 0 | 我 | 爱 |
| 1 | 我爱 | 猫 |
| 2 | 我爱猫 | 。 |
| 3 | 我爱猫。 | 猫 |

Causal Mask 保证位置 0 不能从输入中的“爱、猫、。”偷看答案。

## 3. Batch 与并行训练

`get_batch()` 会随机选择多个起点，把样本堆叠为：

```text
x.shape = [B,T]
y.shape = [B,T]
```

假设 $B=2,T=4$：

```text
x = [[我, 爱, 猫, 。],
     [猫, 爱, 鱼, 。]]

y = [[爱, 猫, 。, 猫],
     [爱, 鱼, 。, 春]]
```

模型一次处理 $B\times T$ 个预测位置。Batch 不是把句子含义合并，而是让相同的计算对多条样本并行执行。

## 4. Logits 与交叉熵的连接

模型输出：

$$
\text{logits}\in\mathbb{R}^{B\times T\times V}
$$

目标为词表编号：

$$
\text{targets}\in\{0,1,\ldots,V-1\}^{B\times T}
$$

PyTorch 的 `F.cross_entropy` 常接收二维预测和一维标签，所以代码先把前两维展平：

```python
loss = F.cross_entropy(
    logits.reshape(B * T, V),
    targets.reshape(B * T),
)
```

这不会打乱对应关系。第一个预测位置仍对应第一个目标，展平只是把 Batch 与时间位置排成一列样本。

整批平均损失可写为：

$$
L=-\frac{1}{BT}\sum_{b=1}^{B}\sum_{t=1}^{T}
\log p\left(y_{b,t}\mid x_{b,\le t}\right)
$$

第一遍只需读成：“把每个位置正确 token 的负对数概率取平均”。

## 5. 一次训练步骤的参数变化

训练开始前，Embedding、Attention、MLP 和 LM Head 中的权重只是随机小数。一次训练步骤发生以下过程：

```text
当前参数
  ↓
前向传播得到 logits
  ↓
交叉熵得到一个标量 loss
  ↓
反向传播得到每个参数的梯度
  ↓
优化器更新参数
  ↓
下一批数据使用新参数重新前向传播
```

对普通梯度下降，单个参数的更新形式是：

$$
\theta_{\text{new}}
=
\theta_{\text{old}}-\eta\frac{\partial L}{\partial\theta}
$$

$\eta$ 是学习率。完整代码使用 AdamW，它会根据梯度历史调整每个参数的有效步长，但仍遵循“利用梯度降低损失”的主线。

**参数与中间激活的区别**

- 参数由训练学习并跨 Batch 保留，例如权重矩阵。
- 中间激活由当前输入临时计算，例如某层的隐藏状态。
- 更新参数后，旧激活对应旧参数，下一批必须重新前向传播。

## 6. 训练模式与评估模式

训练前调用：

```python
model.train()
```

验证或生成前调用：

```python
model.eval()
```

它们主要改变 Dropout 等层的行为。`model.eval()` 不等于关闭梯度，因此验证还要使用：

```python
with torch.no_grad():
    logits, loss = model(x, y)
```

三者职责如下：

| 操作 | 作用 |
|---|---|
| `model.train()` | 让模型处于训练行为模式 |
| `model.eval()` | 让模型处于评估行为模式 |
| `torch.no_grad()` | 不记录反向传播所需计算图，减少内存与计算 |

## 7. 验证集与泛化信号

训练集参与参数更新，验证集只用于观察。常见曲线含义：

```text
训练损失下降，验证损失也下降：模型正在学习可泛化规律
训练损失下降，验证损失上升：可能开始过拟合
两者几乎不下降：实现、学习率、数据或容量可能有问题
出现 NaN：数值溢出、学习率过大或数据异常
```

教学小语料会有强烈重复，验证结果只能检查程序和基本趋势，不能代表真实语言能力。

## 8. Checkpoint 的训练快照

只保存 `model.state_dict()` 足以进行推理，但不足以完整恢复训练。完整 Checkpoint 至少包含：

```text
模型参数
优化器状态
模型结构配置
Tokenizer 词表
当前训练步数
最佳验证损失
随机数状态
```

完整程序把这些内容保存在一个 `.pt` 文件中。恢复时必须先用相同配置创建模型，再载入参数与优化器状态。

Checkpoint 是 Python/PyTorch 二进制文件，不应使用文本编辑器修改，也不要加载来源不可信的文件。

## 9. 生成概率与采样

生成只使用最后一个位置：

```python
next_logits = logits[:, -1, :]
```

温度调整为：

$$
p_i=operatorname{softmax}\left(\frac{z_i}{\tau}\right)
$$

- $\tau<1$：概率更集中，输出更保守。
- $\tau=1$：保持模型原分布。
- $\tau>1$：概率更平坦，输出更多样。
- 程序约定 $\tau\le 0$ 时使用贪心选择。

Top-k 只保留分数最高的 $k$ 个候选，再重新归一化采样。它可以减少极低概率字符造成的离谱输出，但不能修复模型本身没有学会的知识。

## 10. 训练并行与生成串行

训练时完整答案已经存在，Causal Mask 又阻止未来泄漏，因此所有位置的 logits 可以一次并行算出。

生成时第 $t+1$ 个 token 依赖第 $t$ 个 token 的实际采样结果。在新 token 产生前，下一步输入尚不存在，所以时间方向必须串行。

```text
训练：已知整段 x 和 y → 同时计算所有位置的 loss
生成：先得到 token 1 → 才能构造输入并得到 token 2
```

后面学习 KV Cache 时，它只能减少对历史 K、V 的重复计算，不能消除 token 之间的自回归依赖。
