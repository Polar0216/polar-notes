# 总览与导图索引

## 1. 整体主线

线性代数的核心研究对象可以概括为三条线：

1. `方程组线`：从线性方程组出发，得到矩阵、初等变换、秩、可解性。
2. `空间结构线`：从向量组出发，进入线性相关、基、维数、子空间、线性变换。
3. `度量与分类线`：从内积、正交、特征值进一步走向对角化、实对称矩阵、二次型。

把它们合起来看，常见课程的逻辑链条如下：

```text
行列式
  -> 判断可逆
  -> 伴随矩阵 / 克拉默法则

矩阵与线性方程组
  -> 初等变换
  -> 秩
  -> 解的结构

向量组与线性相关
  -> 张成
  -> 极大无关组
  -> 列秩 = 行秩

线性空间
  -> 子空间
  -> 基与维数
  -> 维数公式

线性变换
  -> 核与像
  -> 矩阵表示
  -> 秩-零度定理

特征值与对角化
  -> 相似
  -> 特征子空间
  -> 可对角化判定

内积空间与正交化
  -> 正交基
  -> 格拉姆-施密特
  -> 投影 / 最小二乘

二次型
  -> 对称矩阵
  -> 正交化标准形
  -> 惯性定理
  -> 正定判据
```

## 2. 导图一级节点建议

如果你要做一张总导图，一级节点可以直接用下面八块：

1. 行列式
2. 矩阵与线性方程组
3. 向量组、秩与线性相关
4. 线性空间
5. 线性变换
6. 特征值、特征向量与对角化
7. 内积空间与正交化
8. 二次型

## 3. 各板块之间的依赖关系

- `行列式 -> 矩阵可逆性`：用 `det A != 0` 判定可逆。
- `矩阵与方程组 -> 秩`：行变换把方程组化简，秩控制解的存在与自由度。
- `向量组 -> 线性空间`：向量组的张成和无关性上升为一般线性空间中的基与维数。
- `线性空间 -> 线性变换`：变换本质上是空间之间保持线性结构的映射。
- `线性变换 -> 特征值`：研究一个变换在某些方向上只做伸缩。
- `内积空间 -> 正交对角化`：内积给出长度与角度，正交性让矩阵结构更清晰。
- `二次型 -> 实对称矩阵`：二次型问题可以完全转化为实对称矩阵的正交对角化问题。

## 4. 每章建议提炼的固定模板

为了后续导图统一，建议你在每章都抽取下面四类节点：

1. `基本定义`
2. `核心定理`
3. `关键判据`
4. `典型结论 / 常见联系`

例如“特征值”一章可以拆成：

- 基本定义：特征值、特征向量、特征多项式、特征子空间
- 核心定理：不同特征值的特征向量线性无关
- 关键判据：可对角化充要条件
- 常见联系：相似、迹、行列式、代数重数与几何重数

## 5. 学习与制图顺序建议

如果你想边学边做图，比较顺手的顺序是：

1. `01` 行列式
2. `02` 矩阵与线性方程组
3. `03` 向量组、秩与线性相关
4. `04` 线性空间
5. `05` 线性变换
6. `06` 特征值、特征向量与对角化
7. `07` 内积空间与正交化
8. `08` 二次型

## 6. 导图提炼

- 总根节点：`线性代数`
- 第一层：`行列式 / 矩阵方程组 / 向量组 / 线性空间 / 线性变换 / 特征值 / 内积正交 / 二次型`
- 第二层优先放：`定义、定理、判据、方法`
- 第三层再放：`证明思路、结论之间的联系、典型应用`
