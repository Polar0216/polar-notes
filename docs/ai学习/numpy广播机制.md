# NumPy 广播机制：规则、形状与神经网络中的应用

NumPy 的广播机制可以理解为：

> 当两个数组形状不完全一样时，NumPy 会尝试把较小的数组“虚拟扩展”，让它们能够进行逐元素运算。

常见于：

```python
a + b
a - b
a * b
a / b
```

注意，广播主要是逐元素运算的规则，不是矩阵乘法 `@` 的规则。

---

## 1. 广播的核心判断规则

比较两个数组的 `shape` 时：

> 从最右边的维度开始，向左逐个比较。

每一对维度只要满足下面任意一个条件，就兼容：

1. 两个维度相等；
2. 其中一个维度是 `1`。

如果某个数组维度更少，就把缺少的维度看作在左边补 `1`。

例如：

```
(2, 3)
   (3,)
```

可以看成：

```
(2, 3)
(1, 3)
```

逐维比较：

```
2 和 1：可以
3 和 3：可以
```

所以能够广播。

---

## 2. 广播与维度数量无关

你问过：

> 是不是只有维度相差 1 才可以，差 2 及以上就不行？

不是。

广播和“维度数量相差多少”没有直接关系。

例如：

```
(4, 2, 3)
      (3,)
```

维度数量相差 2，但把第二个数组左边补 `1`：

```
(4, 2, 3)
(1, 1, 3)
```

比较：

```
4 和 1：可以
2 和 1：可以
3 和 3：可以
```

所以可以广播，结果形状是：

```
(4, 2, 3)
```

甚至：

```
(8, 6, 4, 2, 3)
            (3,)
```

也可以，因为第二个可以看作：

```
(1, 1, 1, 1, 3)
```

---

## 3. 维度数量接近也可能无法广播

例如：

```
(2, 3)
   (2,)
```

右对齐后：

```
(2, 3)
(1, 2)
```

最后一维比较：

```
3 和 2
```

既不相等，也没有一个是 `1`，所以不能广播。

因此不能记成：

> 维度差 1 就行。

正确记法是：

> 从右往左比较，每一位必须相等，或者其中一个是 1。

---

## 4. 一维数组形状 `(3,)` 的含义

```python
a = np.array([10, 20, 30])
print(a.shape)
```

输出：

```
(3,)
```

表示：

> 这是一个一维数组，这个维度长度为 3。

它不是严格意义上的“1 行 3 列”。

对比：

```
(3,)    一维，长度 3
(1, 3)  二维，1 行 3 列
(3, 1)  二维，3 行 1 列
```

在广播时，`(3,)` 会从右边对齐，所以经常表现得像 `(1, 3)`。

---

## 5. 二维数组与行方向广播

例如：

```python
a = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

b = np.array([10, 20, 30])
```

形状：

```
a.shape = (2, 3)
b.shape = (3,)
```

右对齐：

```
(2, 3)
(1, 3)
```

可以广播。

相当于：

```
b 被扩展为

[[10, 20, 30],
 [10, 20, 30]]
```

所以：

```python
a + b
```

结果是：

```
[[11, 22, 33],
 [14, 25, 36]]
```

也就是说，`(3,)` 被加到了每一行。

---

## 6. 列方向广播

如果希望每一行加不同的数，需要使用 `(2, 1)`：

```python
b = np.array([
    [10],
    [20]
])
```

形状：

```
(2, 1)
```

和：

```
(2, 3)
```

比较：

```
2 和 2：相等
3 和 1：可以
```

所以能够广播。

相当于：

```
[[10],
 [20]]
```

被扩展为：

```
[[10, 10, 10],
 [20, 20, 20]]
```

因此：

```
[[1, 2, 3],
 [4, 5, 6]]
+
[[10],
 [20]]
```

得到：

```
[[11, 12, 13],
 [24, 25, 26]]
```

---

## 7. 为什么 `(2,)` 不能给两行分别加数

假设：

```
a.shape = (2, 3)
b.shape = (2,)
```

你可能会觉得：

- 第一行加第一个数；
- 第二行加第二个数。

但 NumPy 总是从右边对齐：

```
(2, 3)
   (2,)
```

最后一维比较的是：

```
3 和 2
```

所以失败。

要让它按行分别加，必须改成：

```
(2, 1)
```

例如：

```python
b = np.array([10, 20])[:, None]
```

或者：

```python
b = np.array([10, 20]).reshape(2, 1)
```

---

## 8. 三维示例：`(2, 2, 2)` 与 `(1, 2, 1)`

可以广播。

```
(2, 2, 2)
(1, 2, 1)
```

从右往左比较：

```
2 和 1：可以
2 和 2：相等
2 和 1：可以
```

所以兼容。

最终结果形状是：

```
(2, 2, 2)
```

`(1,2,1)` 会在第一个和第三个维度上扩展。

例如原数组：

```
[
  [
    [10],
    [20]
  ]
]
```

广播后相当于：

```
[
  [
    [10, 10],
    [20, 20]
  ],
  [
    [10, 10],
    [20, 20]
  ]
]
```

---

## 9. 广播结果的形状如何确定

每个维度取两者中较大的那个。

例如：

```
(4, 1, 3)
(1, 5, 1)
```

比较：

```
4 和 1 → 4
1 和 5 → 5
3 和 1 → 3
```

所以结果形状：

```
(4, 5, 3)
```

---

## 10. 常见形状组合汇总

可以广播：

```
(2, 3)       和 (3,)
(2, 3)       和 (2, 1)
(4, 2, 3)    和 (3,)
(4, 1, 3)    和 (1, 5, 1)
(2, 2, 2)    和 (1, 2, 1)
```

不能广播：

```
(2, 3)       和 (2,)
(4, 3)       和 (2, 3)
(2, 3, 4)    和 (2, 2)
```

## 11. 广播在线性层偏置中的应用

你之前的代码：

```python
return x @ self.W + self.b
```

假设：

```
x.shape = (4, 3)
W.shape = (3, 2)
```

矩阵乘法后：

```
x @ W 的形状 = (4, 2)
```

偏置：

```
b.shape = (2,)
```

广播时：

```
(4, 2)
   (2,)
```

等价于：

```
(4, 2)
(1, 2)
```

因此 `b` 会被加到每一个样本上。

## 12. `keepdims=True` 与广播

例如：

```python
x = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
```

如果写：

```python
np.max(x, axis=1)
```

结果形状是：

```
(2,)
```

直接做：

```python
x - np.max(x, axis=1)
```

相当于：

```
(2, 3) - (2,)
```

不能广播。

使用：

```python
np.max(x, axis=1, keepdims=True)
```

结果形状变成：

```
(2, 1)
```

于是：

```
(2, 3) - (2, 1)
```

可以广播。

所以 `keepdims=True` 的常见作用是：

> 保留被压缩的维度，让后续广播更方便。

---

## 13. 核心规则总结

> 广播时，从右往左对齐 shape；对应维度相等，或者其中一个是 1，就可以。维度少的数组在左边补 1。
