# 系统讲解耳机音质（7）：耳机本体与听感

## 二十六、耳机真正决定声音最大的东西是什么？

现在进入真正重要的部分。

相比：

```
16bit vs 24bit
AAC vs LDAC
DAC A vs DAC B
```

很多时候更重要的是：耳机本身。

尤其是：

**频率响应 Frequency Response。**

例如：

```
20Hz ─────────── 20kHz
低频     中频       高频
```

耳机在不同频率输出声音的大小不同。

例如一个耳机：

```
低频 +5dB
中频 0dB
高频 -2dB
```

你可能觉得：

> 浓郁、低频很多、比较暖。

另一个：

```
低频 -3dB
中频 0
高频 +5dB
```

可能觉得：

> 清亮、锐利、细节很多。

这种差距：

**远远大于很多 DAC 的差异。**

---

### “调音”就是这个东西吗？

很大程度上是。

所谓：

> Harman 调音
> V-shaped
> 暖声
> 冷声
> 人声塞
> 低频塞

很多都和：

**Frequency Response**

密切相关。

例如 V-shaped：

```
低频 ↑
中频 ↓
高频 ↑
```

所以叫 V 型。

## 二十七、为什么换耳塞套都可能影响音质？

尤其入耳式耳机：

**密封非常重要。**

如果耳塞没塞严：

```
低频泄漏
↓
Bass大量减少
```

于是你会觉得：

> 怎么这个耳机一点低频都没有？

换一个尺寸合适的耳塞套：

```
密封恢复
↓
低频回来
```

变化可能比：

> 换一根 ¥2000 耳机线

明显得多。

所以耳机圈里一个非常值得记住的优先级：

> **佩戴和密封非常重要。**

## 二十八、动圈、动铁、平板

这是：

**耳机单元原理。**

最常见的动圈：

```
磁铁
↓
线圈
↓
振膜
```

电流通过线圈，线圈在磁场里运动，带动振膜。

非常像一个超小型扬声器。

---

动铁：

使用非常小的电磁结构驱动振膜。

因为体积小：

> 入耳式耳机很容易塞很多颗。

所以你会看到：

```
1动圈 + 4动铁
```

---

平板：

使用非常薄的大面积振膜，在磁场中驱动。

常见于一些大耳。

但：

> **单元种类绝不代表音质等级。**

例如：

```
10单元耳机
```

不一定比：

```
1单元耳机
```

好。

调音和整体设计重要得多。

## 二十九、解析力

这是比较主观的词。

一般在描述：

> 能不能清楚地听见录音里的细节。

比如一段歌里同时有：

```
人声
钢琴
吉他
鼓
弦乐
混响
呼吸
```

如果都比较清晰，大家可能说：

> “解析不错。”

但是“解析”并不是像：

```
1920×1080
3840×2160
```

这样真的存在一个简单的耳机“像素数”。

它和：

频响、失真、瞬态、掩蔽、录音、耳朵等都有关系。

因此：

> **“解析力”更多是听感总结，而不是一个独立物理参数。**

## 三十、声场

例如你闭眼听：

```
歌手：中间
吉他：左边
鼓：后面
小提琴：右边
```

声音似乎有空间位置。

大家把这种空间感称为：

**Soundstage 声场。**

如果感觉：

```
所有声音挤在脑袋里
```

就可能说：

> 声场小。

如果感觉：

```
声音散布得比较开
```

就可能说：

> 声场大。

但耳机并没有真的把歌手放在你前面。

这是：

双耳听觉、录音信息、耳廓传递函数、耳机频响等共同产生的空间错觉。

---

## 三十一、分离度

假设很多乐器同时响：

差的情况下：

```
████████████████
全部糊在一起
```

好的情况下：

```
人声   吉他   鼓   贝斯
 │      │     │    │
```

大家就会形容：

> 分离度比较好。

同样，这也是一个综合听感词。

---

## 三十二、瞬态

例如鼓：

```
砰！
```

是一个非常快速发生的声音。

耳机能否迅速响应这种变化，会影响大家所谓的：

> 瞬态。

于是有人会说：

> 鼓点干脆
> 拖泥带水
> 速度快
> 速度慢

这些词都是在试图描述这种时间变化的听感。
