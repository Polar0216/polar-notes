# 系统讲解耳机音质（4）：手机、DAC、耳放与驱动力

## 十七、为什么有人说手机不如专门播放器？

这里需要非常认真地纠正一个说法：

> **手机并不是天生音质比播放器差。**

区别主要发生在：

**DAC + 耳放 + 电源 + 接口 + 软件播放链路。**

---

### 以前手机为什么可以直接插耳机？

以前手机有：

```
3.5mm
```

内部其实是：

```
CPU
↓
数字音频
↓
手机内部DAC
↓
手机内部耳放
↓
3.5mm
↓
耳机
```

也就是说：

> 手机本身就有 DAC 和耳放。

后来手机把 3.5 mm 去掉了。

现在 USB-C / Lightning 输出通常是：

```
数字音频
```

于是 DAC 被搬到了外面。

---

### 小尾巴

所谓小尾巴

其实就是：

> **一个很小的 USB DAC + Headphone Amplifier。**

英文经常叫：

**Dongle DAC**

或者：

**USB DAC/AMP**

长这样：

```
手机 USB-C
   │
   ▼
┌──────────┐
│  DAC     │
│  AMP     │
└──────────┘
   │
 3.5mm
   │
   ▼
耳机
```

因为它：

> 挂在手机屁股后面像一条小尾巴。

所以中文耳机圈就叫：

**小尾巴。**

---

### USB-C 转 3.5 mm，里面到底是什么？

很多人以为：

```
USB-C
↓
转换一下接口
↓
3.5mm
```

不是这么简单。

很多现代 USB-C 转 3.5 mm 实际上：

```
USB数字信号
↓
DAC芯片
↓
模拟信号
↓
耳放
↓
3.5mm
```

所以那根小东西实际上已经是一套：

**声卡 / DAC / 耳放。**

只是非常小。

---

### DAC

DAC：

**Digital to Analog Converter**

数字 → 模拟转换器。

因为电脑里面是：

```
011010010101...
```

耳机单元却不能直接听 0 和 1。

它需要连续变化的电压：

```
   /\
  /  \
 /    \__
```

所以：

```
数字 PCM
↓
DAC
↓
连续模拟电压
```

才可以送给耳机。

因此：

> **任何数字播放设备最终都一定需要 DAC。**

区别只是：

DAC 在哪里。

蓝牙耳机：

```
DAC在耳机里
```

3.5mm手机：

```
DAC在手机里
```

小尾巴：

```
DAC在小尾巴里
```

播放器：

```
DAC在播放器里
```

---

### 耳放

DAC 输出的电信号可能非常弱。

它还需要：

**Amplifier**

也就是放大器。

耳机专用一般叫：

> 耳机放大器，简称 **耳放**。

所以小尾巴真正的结构通常是：

```
USB
↓
USB Audio Controller
↓
DAC
↓
AMP
↓
3.5 / 4.4mm
```

因此你看到：

> “解码耳放一体机”

基本就是：

```
DAC + AMP
```

---

### 推力

这又是耳机圈特别常出现的一个词。

所谓：

> “这个小尾巴推力够不够？”

本质上是在问：

> **它能不能给耳机提供足够的电压和电流。**

电功率：

$$
P=\frac{V^2}{R}
$$

也可以写：

$$
P=I^2R
$$

其中：

P = 功率
V = 电压
I = 电流
R = 阻抗。

不同耳机对电压、电流要求不同。

---

### 阻抗

你会看到耳机写：

```
16Ω
32Ω
80Ω
250Ω
300Ω
600Ω
```

Ω 是欧姆，表示：

**阻抗。**

但非常重要：

> **不能只靠阻抗判断耳机好不好推。**

还必须看：

**灵敏度。**

---

### 灵敏度

灵敏度大概是在告诉你：

> 给耳机一定电功率/电压，它能发出多大的声音。

比如：

```
110 dB/mW
```

就代表：

给 1 mW 功率时可以达到大约 110 dB SPL。

所以可能出现：

```
300Ω + 高灵敏度
```

并没有想象中那么难推。

也可能：

```
32Ω + 很低灵敏度
```

反而需要不少功率。

典型例子就是部分平板耳机。

因此：

> **“高阻 = 难推，低阻 = 好推”只是一种非常粗糙的说法。**
