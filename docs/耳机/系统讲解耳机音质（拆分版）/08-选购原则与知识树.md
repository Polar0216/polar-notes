# 系统讲解耳机音质（8）：选购原则与知识树

## 三十三、“音质影响优先级”

对普通人来说，可以大致想成：

```
耳机本身 / 调音
        ↓
佩戴与密封
        ↓
录音 / 混音 / 母带
        ↓
EQ
        ↓
是否正确驱动
        ↓
音源是否严重有损
        ↓
蓝牙Codec
        ↓
DAC之间的小差异
        ↓
超高采样率/位深
```

不是绝对排序，但非常适合防止小白走偏。

尤其：

> **不要拿着一个自己根本不喜欢调音的耳机，然后花 ¥3000 换 DAC 试图救它。**

换耳机可能效果大得多。

---

## 三十四、蓝牙 vs 有线总结一下

可以想成：

### 有线 USB

```
FLAC
↓
PCM
↓
USB
↓
DAC
↓
AMP
↓
耳机
```

最大优势：

**数字链路不需要蓝牙有损压缩。**

---

### 蓝牙

```
FLAC
↓
PCM
↓
AAC / LDAC / aptX / LC3
↓
Bluetooth
↓
解码
↓
DAC
↓
AMP
↓
耳机
```

多了一道：

> Bluetooth Codec。

因此理论数据完整度有线占优势。

但是蓝牙同时拥有：

无线、ANC、DSP、通话、便利性、空间音频等巨大优势。

所以现实里并不是：

> 有线高级，蓝牙垃圾。

而是两个不同方向的产品。

---

## 三十五、手机 vs DAP

### 手机 + 蓝牙耳机

```
手机
↓
Bluetooth Codec
↓
耳机内部DAC/AMP
```

播放器自己的高级 DAC 基本没意义。

---

### 手机 + 小尾巴 + 有线耳机

```
手机
↓ USB
小尾巴 DAC
↓
小尾巴 AMP
↓
耳机
```

可以获得非常好的音质。

---

### 专业 DAP + 有线耳机

```
DAP
↓
内部高级DAC
↓
强耳放
↓
耳机
```

优势主要在：

驱动力、接口、独立设备、功能、储存、供电和完整音频系统。

## 三十六、判断音频产品的简单原则

以后看到商家宣传：

> **32bit / 768kHz！**

先问：

**耳机本身怎么样？**

看到：

> **LDAC 990 kbps！**

先问：

**手机支持 LDAC 吗？**

看到：

> **4.4 全平衡！**

先问：

**我这个耳机真的需要这么大推力吗？**

看到：

> **8颗动铁！**

先问：

**频响和调音怎么样？**

看到：

> **Hi-Res！**

先问：

**它只是“支持高规格”，还是实际声音真的好？**

看到：

> **旗舰 DAC 芯片！**

先问：

**整机电路设计、耳放和输出性能如何？**

这几句话基本能让你避开耳机圈相当一部分营销话术。

## 三十七、最后给你一张完整的“耳机知识树”

```
                    音频
                     │
       ┌─────────────┼─────────────┐
       │             │             │
      音源          传输          播放
       │             │             │
       │             │             │
 PCM / DSD       有线 / 蓝牙     DAC
       │             │             │
采样率/位深      USB            AMP
       │          3.5mm            │
       │          Bluetooth      耳机
文件编码             │             │
 │                   │         动圈/动铁/平板
 ├ WAV               │             │
 ├ FLAC          Bluetooth Codec   │
 ├ ALAC              │          频率响应
 ├ MP3               ├ SBC       失真
 ├ AAC               ├ AAC       灵敏度
 └ Opus              ├ aptX      阻抗
                     ├ LDAC
                     └ LC3
```

如果现在只要求你记住 **六句话**，我会让你记：

> **1. 耳机本身通常比 DAC 和编码格式更重要。**
> **2. FLAC/ALAC 是无损文件压缩；AAC/MP3 通常是有损文件编码。**
> **3. Bluetooth 还需要额外的 SBC/AAC/LDAC/aptX/LC3 等传输编码。**
> **4. DAC 负责数字→模拟，AMP 负责把模拟信号放大。**
> **5. “小尾巴”基本就是插在手机上的迷你 DAC + 耳放。**
> **6. 手机 + 好小尾巴完全可以成为很高质量的音源，专业播放器并不是音质魔法盒。**

如果你愿意继续往下学，我下一步最推荐直接给你讲 **“如何看懂一张耳机参数表和测评”**：阻抗、灵敏度、频响曲线、THD、SNR、输出功率、dB、mW、Vrms 到底怎么看，以及怎么判断“这个耳机我的手机/小尾巴推不推得动”。这一部分学会之后，基本就从“完全小白”进入能自己看设备参数的阶段了。
